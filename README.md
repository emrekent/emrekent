## How I build

| Principle | What it means in the repo |
|---|---|
| Failure is visible | Retries, telemetry and explicit failure states. A system that never reports failure is not being measured |
| Human review is a node | Not a disclaimer in the footer. It is a gate the flow must pass through |
| Documented as built | Not written afterwards. The handover is part of the build |
| Scoped down and said so | A narrow version with its limitation stated beats a broad one that overpromises |
